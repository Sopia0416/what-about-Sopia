# 阿雯 (Sophia) 個人品牌與探索網站

這是一個為 **阿雯 (Sophia)** 量身打造的個人專屬品牌網站，融合溫暖人文與科學思維的現代雜誌風格（Warm Editorial & Organic Style）。

---

## 🌟 網站特色

1. **原汁原味呈現個人文案**：
   - 完整收錄您所撰寫的自我介紹、專業背景（中國醫藥大學 中國藥學暨中藥資源學系）。
   - 「思考與觀察步調」（A Little More About Me）四大思維面向。
   - 「核心信念」（What I Believe）哲學金句。
   - 「探索手記」（Still Exploring）專欄雛形與文章卡片分類過濾。

2. **生活剪影拍立得畫廊（Gallery）**：
   - 整合您上傳的 5 張生活寫真與夕暮暮色棉花糖照片。
   - 拍立得邊框與微傾斜質感，支援**點擊放大檢視（Lightbox）**功能。

3. **互動體驗與設計細節**：
   - **今日探索小語輪播**：動態隨機切換您心中的探索金句。
   - **手記分類篩選器**：可一鍵切換「中藥科學」、「文化與產業轉型」、「日常隨想」。
   - **聯絡與留言區塊**：訪客互動留言表單與社群連結預留位置。
   - **響應式排版（RWD）**：手機、平板、電腦螢幕皆能完美適配呈現。

## 🚀 如何在電腦上開啟瀏覽

您只需要點兩下開啟專案資料夾內的 `index.html`，即可在任何瀏覽器（Chrome、Safari、Edge）中直接預覽！

```bash
# 或在終端機中直接開啟：
open /Users/wuyunjie/Desktop/sophia-website/index.html
```

## 🌐 未來上線部署建議

若未來希望將網站發布至網路上供朋友、教授、面試官瀏覽，可以免費使用：
1. **GitHub Pages**：建立一個 GitHub Repository 並將此資料夾推上，開啟 Pages 即可獲得 `https://<帳號>.github.io`。
2. **Vercel / Netlify**：直接拖曳此資料夾即可秒速上線，並獲得專屬免費網址與 SSL 憑證。
